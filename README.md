# Scooter Scout

Erstelle eine moderne, hochwertige und sehr übersichtliche Website für eine E-Scooter-Vergleichsplattform. Die Website soll sich vor allem an junge Leute, E-Scooter-Fans, Pendler und Einsteiger richten und sich optisch wie eine professionelle moderne Produktvergleichsseite anfühlen.



Grundidee



Die Website soll Nutzern helfen, den perfekten E-Scooter zu finden und verschiedene Modelle detailliert miteinander zu vergleichen.



Der zentrale Bereich der Website ist eine große E-Scooter-Datenbank mit mindestens 200 verschiedenen Modellen von vielen bekannten Herstellern.

Mobile Version

Die Website muss auf Smartphones hervorragend funktionieren.



Besonders wichtig, weil viele Nutzer die Website auf dem Handy besuchen.



Filter sollen auf Mobile über einen großen "Filter"-Button geöffnet werden.



Vergleiche sollen horizontal scrollbar sein.

Rechtliche Hinweise

Zeige bei Geschwindigkeits- und Zulassungsdaten einen klaren Hinweis:



"Technische Daten können je nach Version, Land, Softwarestand und Konfiguration abweichen. Prüfe vor dem Kauf die Angaben des Herstellers und die für dein Land geltenden Vorschriften."



Bei ABE-Modellen muss klar zwischen tatsächlich zugelassenen Versionen und internationalen Versionen unterschieden werden.
